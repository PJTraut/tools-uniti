# Lucide icons bundled with UNITI

Source: https://github.com/lucide-icons/lucide

Release: **1.42.0**

Pinned upstream commit: `3859eb20fabe7fd95652fcd4395843b6c0bcdd01`

These SVGs are unmodified copies of the corresponding files in upstream's
`icons/` directory. Only the nine icons used by Find/Replace are bundled.
UNITI renders each SVG to a silhouette and tints it using the active application
palette, including native text opacity. No font installation or runtime download
is needed.

The accompanying upstream `LICENSE` includes the Lucide ISC license and the
MIT notice for icons derived from Feather. Retain the complete license when
redistributing this directory.
