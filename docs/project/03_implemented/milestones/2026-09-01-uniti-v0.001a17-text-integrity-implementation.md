**Goal:** Make encoding, BOM, byte order, line endings, malformed bytes, Save As identity, and save-state transitions explicit and verifiably lossless.

**Architecture:** Add exact Qt-free format values and inspection reports around the existing byte source, decoder, piece table, EOL analyzer, and atomic-save path. Stage and verify every output before replacement; keep `Document` authoritative for text and saved state while application-owned dialogs and `UNITIMainWindow` coordinate user choices, warnings, and tabs.

**Tech Stack:** Python 3.12+, PySide6 6.8+, pytest 9+, `pathlib`, `codecs`, `hashlib`, existing UNITI core/app/resource services.

**Spec:** `docs/project/03_implemented/designs/2026-09-01-uniti-v0.001a17-text-integrity-design.md`

## Global Constraints

- Opening and saving a file must not silently change its encoding or line endings.
- Exact encoding profiles are `UTF-8`, `UTF-8 BOM`, `Windows-1252`, UTF-16 LE/BE with and without BOM, and UTF-32 LE/BE with and without BOM.
- Omission of `BOM` means no BOM; codec, byte order, and BOM changes are encoding changes.
- Encoding confidence below `0.75`, contradictory evidence, or malformed preview bytes requires serious confirmation before opening.
- Encoding issues and line-ending issues are reported separately.
- Line endings are `LF`, `CRLF`, `CR`, or `Mixed`; normalization is always explicit.
- Malformed source bytes remain byte-preserved under the same-profile `Preserve` path and block transformation while unresolved.
- Every Save and Save As stages, flushes, verifies, and atomically replaces; failure leaves destination and document state unchanged.
- Save As to a different resolved path exports a copy, leaves the source tab unchanged, and opens the output in an active tab.
- An existing clean open target requires two overwrite confirmations; an existing dirty open target cannot be replaced.
- Overwriting an existing file with another encoding profile requires an exact before/after warning on Save and Save As.
- Qt remains absent from `src/uniti/core`, `src/uniti/regex`, and `src/uniti/resources`.
- New inspection and verification paths are streaming or bounded-memory; realistic multi-gigabyte performance proof remains a18.
- Every behavior change follows RED -> GREEN -> refactor and receives a focused commit.
