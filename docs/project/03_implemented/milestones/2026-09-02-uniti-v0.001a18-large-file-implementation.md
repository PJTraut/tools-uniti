# UNITI v0.001a18 Large-File Alpha Implementation Plan

Status: implemented and verified

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make 10–100 MiB editing routine, keep sparse 1 GiB opening lazy, and establish a host-aware user-experience performance suite that governs bounded resources and progressive work.

**Architecture:** Package one validated TOML authority for UX thresholds and resource policy, measure each scenario in an isolated child process, and extend the Qt-free `ResourceManager` into the sole cache/task/load authority. Long operations consume immutable document snapshots in bounded chunks, publish revision-bound results, and surface progress through a thin Qt bridge while the authoritative `Document` retains text, history, format, and save-state ownership.

**Tech Stack:** Python 3.12+, PySide6 6.8+, Qt Widgets, pytest 9+, third-party `regex==2026.5.9`, `tomllib`, `importlib.resources`, `mmap`, `array`, `tempfile`, `subprocess`, `threading`, `concurrent.futures`, and existing UNITI core/resource services.

**Spec:** `docs/project/03_implemented/designs/2026-09-02-uniti-v0.001a18-large-file-design.md`

## Global Constraints

- Performance is a user-experience contract: time to usable content, main-thread heartbeat, interaction latency, cancellation, progress, peak/retained RSS, and safe completion.
- Canonical values come from packaged `src/uniti/resources/performance_policy.toml`; production and benchmarks do not duplicate those constants.
- Quick uses 10 MiB, Routine uses 100 MiB, and Design Target uses a sparse 1 GiB source.
- Open to usable content fails above 1,000 ms on an eligible host.
- GUI heartbeat fails above 33 ms p95 or 100 ms maximum during measured long work.
- Normal cancellation fails above 250 ms; timeout-bound regex cancellation fails above 750 ms.
- First progress fails above 250 ms and progress gaps fail above 500 ms, except operations completed within the first-progress limit.
- Peak RSS increase fails above the smaller of 512 MiB and 12.5% of physical RAM; retained RSS fails above 64 MiB.
- Compatible-baseline regressions warn at 15% and fail at 25%.
- Streaming work bypasses reusable decoded-window caches.
- Long work never materializes the complete source as one Python `bytes` or `str` and never runs synchronously on the GUI thread.
- Search, replacement preparation, indexing, and output work publish only when revision and identity remain current.
- Save/Save As retain every a17 staged-verification, exact-format, external-change, atomic-replacement, tab, and document-state invariant.
- Replace All remains one document transaction and one Undo operation; unsafe estimated plans are refused before mutation.
- Qt remains absent from `src/uniti/core`, `src/uniti/regex`, and `src/uniti/resources`.
- Host preflight and benchmarks are local-only and perform no network access or telemetry.
- Qt tests use `QApplication.processEvents()` with an explicit monotonic deadline; a18 does not add `pytest-qt`.
- No regex-language, syntax-highlighting, file-template, project/workspace, plugin, or preferences expansion enters a18.
- Every behavior change follows RED -> GREEN -> refactor and receives a focused commit.

```python
@dataclass(frozen=True, slots=True)
class HostResourceProfile:
    cpu_model: str
    architecture: str
    physical_cores: int
    logical_cores: int
    physical_memory: int
    platform: str
    platform_release: str
    temp_root: Path


@dataclass(frozen=True, slots=True)
class ResourceSnapshot:
    physical_memory: int
    available_memory: int
    process_rss: int
    load_per_logical_core: float | None
    free_disk: int
    cache_used: int
    active_workers: int
    queued_tasks: int
    captured_at: float


class ResourceSampler:
    def sample(self, *, cache_used_bytes: int, active_workers: int, queued_tasks: int) -> ResourceSnapshot:
        memory = self._memory_probe()
        load = self._load_probe()
        normalized = None if load is None else max(0.0, load) / self.profile.logical_cores
        return ResourceSnapshot(
            physical_memory=memory.physical,
            available_memory=memory.available,
            process_rss=max(0, self._rss_probe()),
            load_per_logical_core=normalized,
            free_disk=max(0, self._disk_probe(self.profile.temp_root)),
            cache_used=max(0, cache_used_bytes),
            active_workers=max(0, active_workers),
            queued_tasks=max(0, queued_tasks),
            captured_at=self._clock(),
        )
```

Use bounded platform helpers: `sysctl` with a five-second timeout on macOS, `/proc/cpuinfo` and `/proc/self/statm` on Linux, and `ctypes` `GetProcessMemoryInfo` on Windows. Missing platform evidence falls back to `platform.processor()`, `os.cpu_count()`, and `0`/`None`; it never aborts application startup.

```python
class ResultState(StrEnum):
    PASS = "PASS"
    WARN = "WARN"
    FAIL = "FAIL"
    INVALID = "INVALID"
    NOT_RUN = "NOT RUN"


@dataclass(frozen=True, slots=True)
class MetricSample:
    values: tuple[float, ...]

    @property
    def median(self) -> float:
        return statistics.median(self.values)

    @property
    def p95(self) -> float:
        ordered = sorted(self.values)
        return ordered[min(len(ordered) - 1, math.ceil(len(ordered) * 0.95) - 1)]


@dataclass(frozen=True, slots=True)
class ScenarioResult:
    schema: int
    scenario: str
    state: ResultState
    metrics: Mapping[str, MetricSample]
    facts: Mapping[str, object]
    messages: tuple[str, ...]


def generate_corpus(spec: CorpusSpec, root: Path) -> CorpusManifest:
    root.mkdir(parents=True, exist_ok=False)
    path = root / f"{spec.kind.value}.txt"
    digest = hashlib.sha256()
    with path.open("wb") as handle:
        for chunk in _corpus_chunks(spec):
            handle.write(chunk)
            digest.update(chunk)
    if path.stat().st_size != spec.size_bytes:
        raise RuntimeError("generated corpus size mismatch")
    return CorpusManifest(1, spec, path, digest.hexdigest())
```

The parent launches `sys.executable -m benchmarks.runner --child <scenario> <manifest-json>`, owns the timeout, and parses one JSON object from a dedicated result file rather than mixing it with Qt stderr. Every child reports peak RSS and cleanup state. The initial scenarios measure current Open/first paint, far line navigation, no-match search heartbeat/cancellation/RSS, and verified Save As.

```python
class TaskKind(StrEnum):
    SAVE = "save"
    RECOVERY = "recovery"
    NAVIGATION = "navigation"
    SEARCH = "search"
    REPLACE = "replace"
    INDEX = "index"
    EOL = "eol"
    PREFETCH = "prefetch"


@dataclass(frozen=True, slots=True)
class TaskSpec:
    task_id: str
    kind: TaskKind
    priority: WorkPriority
    foreground: bool
    document_key: str | None
    revision: int | None
    estimated_memory_bytes: int
    estimated_disk_bytes: int


@dataclass(frozen=True, slots=True)
class TaskProgress:
    task_id: str
    phase: str
    completed: int
    total: int | None
    updated_at: float
    cancellable: bool


class TaskContext:
    def report(self, phase: str, completed: int, total: int | None, *, cancellable: bool = True) -> None:
        self.token.raise_if_cancelled()
        self._handle._set_progress(phase, completed, total, cancellable)


class TaskCoordinator:
    def submit(self, spec: TaskSpec, fn: Callable[[TaskContext], T]) -> TaskHandle[T]:
        token = CancellationToken()
        handle = TaskHandle(spec, token, self._clock)
        handle._future = self._pool.submit(
            spec.priority,
            self._run,
            handle,
            fn,
            token=token,
        )
        return handle
```

Workers wait on a condition before taking another item when `active_count >= active_limit`. `set_active_limit` clamps to `1..max_workers` and wakes waiters. The coordinator refuses estimated work that exceeds current memory/disk admission, pauses only non-foreground kinds, and preserves priority plus FIFO sequence.

`ResourceManager.observe_resources` applies the approved Normal/Busy/Constrained/Critical table, changes active admission and cache target, and requires two healthier samples before recovery. Keep `observe_memory` as a compatibility wrapper.

```python
class LinearBoundaries(Sequence[int]):
    __slots__ = ("first", "step", "count")

    def __init__(self, first: int, step: int, count: int) -> None:
        self.first, self.step, self.count = first, step, count

    def __len__(self) -> int:
        return self.count

    def __getitem__(self, index):
        if isinstance(index, slice):
            return tuple(self[item] for item in range(*index.indices(self.count)))
        if index < 0:
            index += self.count
        if index < 0 or index >= self.count:
            raise IndexError(index)
        return self.first + index * self.step
```

```python
@dataclass(frozen=True, slots=True)
class DocumentSaveRequest:
    snapshot: DocumentReadSnapshot
    destination: Path
    output_format: OutputFormat
    expected_destination_identity: FileIdentity | None
    in_place: bool


@dataclass(slots=True)
class PreparedDocumentSave:
    request: DocumentSaveRequest
    staged: StagedSave

    def discard(self) -> None:
        discard_staged_document(self.staged)
        self.request.snapshot.close()


def prepare_document_save(request: DocumentSaveRequest, context: TaskContext) -> PreparedDocumentSave:
    staged = stage_document(
        request.snapshot.source,
        request.snapshot.piece_table,
        source_profile=request.snapshot.source_profile,
        destination=request.destination,
        output_format=request.output_format,
        progress=lambda phase, done, total: context.report(phase, done, total),
        cancelled=lambda: context.token.cancelled,
    )
    verify_staged_document(
        staged,
        request.snapshot.iter_text(),
        progress=lambda phase, done, total: context.report(phase, done, total),
        cancelled=lambda: context.token.cancelled,
    )
    return PreparedDocumentSave(request, staged)
```

For in-place Save, `commit_prepared_save` performs atomic replacement, reloads source services, and advances history exactly as a17. Export commits and opens/reloads one target tab without retargeting or cleaning the source document.
