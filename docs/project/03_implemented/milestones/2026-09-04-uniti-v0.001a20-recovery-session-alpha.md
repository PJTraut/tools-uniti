## Goal

Ensure crashes and restarts do not casually lose work.

## Approved focus

- atomic save and bounded cleanup of stale UNITI-owned temporary state;
- incremental recovery journals, integrity validation, and safe unsaved-edit recovery;
- settings schema migration and corrupted-settings fallback;
- one persistent service with safe local launch forwarding;
- multiple windows, detachable tabs, and horizontally/vertically split document views;
- safe persistence of editor, Find/Replace, document history, pane, and window state; and
- depth-and-byte-bounded history with seven-day retention.

Recovery never modifies the original file until an explicit commit or save action.

## Acceptance boundary

The governing design requires one session writer, a persistent zero-window service, multi-window/split shared-document authority, exact restoration of admitted document and Find/Replace histories, SHA-256 external-change choices, and recovery that preserves unsaved text plus Undo/Redo semantics. a20 must pass failure-injected persistence and crash tests, complete ordinary verification, deep self-check, offscreen and native smoke, and the existing performance/integrity gates. Low-disk behavior is tested only through injected capacity and write-failure conditions; tests never fill the real filesystem.
