# UNITI v0.001a4 Streaming Save Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Safely save edited UNITI documents through bounded streaming writes with explicit encoding/EOL conversion and a byte-preserving fast path.

**Architecture:** Add immutable piece-segment iteration so the writer can direct-copy untouched source byte ranges when encoding/EOL are preserved. All conversions use logical Unicode chunk streaming, a stateful EOL normalizer, strict incremental encoding, same-directory temp files, fsync, and atomic replace. `Document.save` exposes the policy without moving storage ownership into the UI.

**Tech Stack:** Python 3.12+, `codecs`, existing `ByteSource`/`PieceTable`, pytest.

**Spec:** `docs/project/03_implemented/designs/2026-08-31-uniti-v0.001-alpha-completion-design.md`

## Global Constraints

- No whole-document Unicode/bytes copy.
- Untouched invalid source bytes must survive unchanged when encoding/EOL are preserved.
- Encoding conversion is strict; no silent replacement.
- EOL conversion recognizes CRLF as one sequence across chunk/piece boundaries.
- Save uses temporary file + flush/fsync + `os.replace`.
- Version after milestone: `v0.001a4` / `0.1a4`.
