# UNITI v0.001a7 Resource and Worker Services Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Qt-independent cancellation, memory budgeting/cache eviction, and bounded priority worker execution for the first desktop alpha.

**Architecture:** `uniti.resources` owns disposable-resource policy and background execution without importing Qt. Memory policy follows Architecture v0.1's effective-available/host-reserve formulas; cache entries carry byte cost and eviction priority. Worker execution uses a bounded `PriorityQueue` plus daemon worker threads and standard `Future` results so the later Qt layer can bridge results through signals without moving document ownership into Qt.

**Tech Stack:** Python 3.12+, stdlib `threading`, `queue`, `concurrent.futures.Future`; optional `psutil` detected at runtime; pytest.

**Spec:** `docs/project/03_implemented/designs/2026-08-31-uniti-v0.001-alpha-completion-design.md`

## Global Constraints

- `uniti.resources` must not import PySide6/PyQt.
- Interactive/visible work has lower numeric priority than search/index/prefetch work.
- Cancellation is cooperative and thread-safe.
- Disposable cache accounting is explicit in bytes and never includes user edit/history state.
- Automatic memory target follows: reserve=`max(2 GiB, min(8 GiB, 10% physical))`; claimable=`max(0, effective_available-reserve)`; target=`min(50% physical, 70% claimable)`.
- Version after milestone: `v0.001a7` / `0.1a7`.
