# UNITI v0.001a21 Find/Replace Docking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Present the one service-owned Find/Replace surface either full-width below the active editor window or as its existing floating tool without losing state.

**Architecture:** Convert the current modeless dialog into one bottom-only `QDockWidget` whose existing controller, inputs, report, results, and histories remain singular. `UNITIService` owns placement and moves that same widget when active-window focus changes; actual target changes keep the existing generation/revision invalidation rules.

**Tech Stack:** Python 3.12+, PySide6 6.8+ `QDockWidget`/`QMainWindow`, pytest 9+, existing `FindReplaceWindow`, `UNITIService`, command registry, session-schema-2 placement field, and bounded F/R histories.

**Spec:** [Editor Layout and Visibility design](../designs/2026-09-05-uniti-v0.001a21-editor-layout-visibility-design.md)

- [x] **Step 4: Implement explicit attachment state without resetting controller state**

Add idempotent placement methods and suppress placement-signal recursion during restore/host moves:

```python
@property
def placement(self) -> str:
    return self._placement

def attach_to(self, window: QMainWindow) -> None:
    if not isinstance(window, QMainWindow):
        raise TypeError("Find/Replace host must be a QMainWindow")
    old = self.parentWidget()
    if isinstance(old, QMainWindow) and old is not window:
        old.removeDockWidget(self)
    window.addDockWidget(Qt.DockWidgetArea.BottomDockWidgetArea, self)
    self.setFloating(False)
    self._set_placement("attached")

def detach(self) -> None:
    self.setFloating(True)
    self.setWindowFlag(Qt.WindowType.Tool, True)
    self.setWindowFlag(Qt.WindowType.WindowStaysOnTopHint, True)
    self._set_placement("detached")
    self.show()
```

Update export/restore so geometry comes from `_detached_geometry` and placement is round-tripped. `moveEvent` and `resizeEvent` update/emit geometry only while detached. `closeEvent` hides/cancels only the existing capture presentation work; `shutdown` remains the only final teardown.

Implement service methods around its existing lazy singleton:

```python
def attach_find_replace(self) -> None:
    self._find_replace_placement = "attached"
    self._sync_find_replace_host()

def detach_find_replace(self) -> None:
    self._find_replace_placement = "detached"
    if self._find_replace is not None:
        self._find_replace.detach()

def _sync_find_replace_host(self) -> None:
    panel = self._find_replace
    if panel is None or self._find_replace_placement != "attached":
        return
    window = self.windows.active_window or self.windows.most_recent_window
    if window is None:
        panel.hide()
        panel.setParent(None)
        return
    window.host_find_replace(panel)
```

Call `_sync_find_replace_host` after window registration, active-view changes, session placement restoration, and before an attached host is destroyed. When zero windows remain, hide and detach Qt ownership without calling `shutdown`.

- [x] **Step 4: Remove per-window ownership side effects**

In `UNITIMainWindow.__init__`, do not hide or geometrically reset an already-created service panel. Keep action/event-filter bindings per window but enable them only for the active service window. Add explicit host/release helpers:

```python
def host_find_replace(self, panel: FindReplaceWindow) -> None:
    panel.attach_to(self)
    if panel.isVisible():
        panel.show()

def release_find_replace(self, panel: FindReplaceWindow) -> None:
    if panel.parentWidget() is self:
        self.removeDockWidget(panel)
        panel.setParent(None)
```

The Find and Replace commands call the service placement-aware focus methods. Closing an ordinary window asks the service to release/move the dock before the window unregisters. Only explicit service Quit calls `panel.shutdown()`.
