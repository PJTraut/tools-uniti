# UNITI v0.001a16 Startup and Bootstrap Workstream Implementation Plan

Status: implemented workstream; retained history, not the complete a16 product milestone

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a safe explicit bootstrap, owned Python runtime, phased normal startup, bounded self-checks, and complete v0.001a16 project documentation without allowing ordinary startup to mutate dependencies.

**Architecture:** A standard-library shim selects Python 3.12+ and delegates to a Qt-free bootstrap package that owns environment discovery, markers, locking, dependency installation, and relaunch. The application side uses shared atomic state primitives, a Qt-free startup coordinator, bounded capability/cleanup probes, and lazy Qt callbacks; self-check reuses those services and the established core smoke paths.

**Tech Stack:** Python 3.12+, standard library (`argparse`, `dataclasses`, `enum`, `json`, `pathlib`, `subprocess`, `tomllib`, `venv`), `regex==2026.5.9`, optional `PySide6>=6.8`, `pytest>=9`, Git.

**Spec:** `docs/project/03_implemented/designs/2026-09-01-uniti-v0.001a16-startup-bootstrap-design.md`

## Global Constraints

- A discoverable Python 3.12 or newer must already exist on the host.
- Bootstrap may mutate only a verified UNITI-owned environment.
- Normal `uniti` startup never invokes `pip`, repairs dependencies, or accesses the network.
- Source mode uses exactly `<source-root>/.venv`; local mode uses `AppPaths.local_runtime_dir`.
- Source `.venv` adoption requires a valid virtual environment; an existing unmarked local target is refused.
- Dependency declarations in `pyproject.toml` are canonical; every pip call is `<runtime-python> -m pip`.
- Managed environments are never deleted, cleared, or silently replaced.
- Persisted files are written atomically; malformed supported files are preserved and unsupported future schemas remain untouched.
- Capability and cleanup work is bounded and confined to UNITI-owned paths.
- PySide6 is imported only after CLI parsing and only for GUI work.
- Existing document, regex, save, recovery, resource, and Qt ownership invariants remain unchanged.
- The completed versions are `v0.001a16` and `0.1a16`; integration is a normal non-force push of `main` with no tag.

class UnsupportedSetupSchema(ValueError):
    pass

def empty_setup_state() -> dict[str, object]:
    return {
        "schema": SETUP_STATE_SCHEMA,
        "uniti": {}, "startup": {}, "install": {}, "python": {},
        "platform": {}, "dependencies": {},
        "schemas": {"settings": 1, "recovery": 2, "session": 1},
        "resources": {}, "capabilities": {}, "session_id": None,
        "last_bootstrap": None, "last_startup_attempt": None,
        "last_successful_startup": None,

def atomic_write_json(path: Path, payload: Mapping[str, object]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    with tempfile.NamedTemporaryFile("w", encoding="utf-8", dir=path.parent,
                                     prefix=f".{path.name}.", suffix=".tmp",
                                     delete=False) as handle:
        temporary = Path(handle.name)
        json.dump(payload, handle, ensure_ascii=False, indent=2, sort_keys=True)
        handle.write("\n")
        handle.flush()
        os.fsync(handle.fileno())
    os.replace(temporary, path)
    sync_directory(path.parent)
```

`SetupStateStore.prepare()` returns defaults when absent, preserves malformed content to `<name>.<UTC timestamp>.invalid`, rejects non-dict and future schemas without replacing them, and fills missing schema-1 sections. `AppPaths.ensure()` creates config, data, state, cache, recovery, logs, temp, and sessions.

RUNTIME_MARKER_SCHEMA = 1
RUNTIME_MARKER_NAME = ".uniti-runtime.json"

class EnvironmentManager:
    def ensure(self, *, repair: bool = False) -> tuple[Path, RuntimeMarker]:
        if not self.environment_path.exists():
            return self._create_marked_environment()
        marker = self._read_marker()
        if marker is None and self.mode is BootstrapMode.SOURCE:
            return self._adopt_source_environment()
        if marker is None:
            raise BootstrapError("existing local runtime is not UNITI-owned", 11)
        self._validate_marker(marker)
        return runtime_python(self.environment_path, self.platform_name), marker
```

Lock with `os.open(path, os.O_CREAT | os.O_EXCL | os.O_WRONLY, 0o600)`; retain stale locks as timestamped `.stale`, reject live PIDs, and remove only the lock acquired by the current session.
