# UNITI v0.001a11 Data Integrity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminate the alpha10 data-integrity defects in recovery, atomic save metadata, BOM handling, and current-path reinterpretation.

**Architecture:** Recovery metadata will distinguish source decoding from pending output policy. Atomic save continues using same-directory temporary files but captures/restores source metadata before replace. Explicit decoders retain matching BOM metadata. Reinterpretation uses the current logical document path, never the stale original source path.

**Tech Stack:** Python 3.12+, stdlib filesystem/codec APIs, pytest.

**Spec:** `docs/project/03_implemented/designs/2026-08-31-uniti-v0.001a11-a15-remediation-design.md`

## Global Constraints

- Keep `uniti.core` Qt-free.
- Preserve invalid source bytes on ordinary save.
- Recovery must fail closed on unsafe/ambiguous journal metadata.
- Version after milestone: `v0.001a11` / `0.1a11`.
