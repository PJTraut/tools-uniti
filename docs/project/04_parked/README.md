# Parked UNITI Capabilities

Parked capabilities are deliberately outside current architecture or scope. They are retained for later re-evaluation, but they have no delivery sequence, target version, or implementation commitment.

## Promotion rule

A parked capability can enter `02_plans` only after:

1. re-evaluating product fit and user value;
2. assessing architectural ownership, dependencies, resource cost, security, and cross-platform impact;
3. accepting a durable decision that changes or extends the current boundary; and
4. assigning the resulting milestone a position in `ROADMAP.md`.

If re-evaluation does not justify promotion, update the parked record's rationale or trigger and leave it here.

See the [Capability Catalog](CATALOG.md) and [Project Grammar](../00_governance/GRAMMAR.md).
