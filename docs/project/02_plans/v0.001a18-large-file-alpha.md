## Goal

Prove UNITI's bounded document architecture under realistic scale.

## Approved focus

- make 10–100 MB files routine while retaining 1 GiB as a design target rather than an artificial ceiling;
- enforce bounded RAM/cache use and avoid accidental whole-file Python copies;
- keep rendering viewport-driven and indexes progressive/chunked;
- keep search/replace asynchronous and cancellable with resource-aware workers;
- keep wrapped rendering virtualized and lazy; and
- establish a repeatable benchmark corpus with latency and memory measurements.

## Acceptance boundary

The governing design defines one adjustable threshold table, read-only host preflight, controlled and real-world measurement modes, progressive resource-aware task execution, bounded cache/index behavior, and explicit GUI resource/load indication. a18 must pass the ordinary suite, quick performance suite, controlled 100 MiB routine suite, sparse 1 GiB design probe, and native macOS user-experience run without weakening a17 text-integrity guarantees.
