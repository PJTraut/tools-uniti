# UNITI v0.001a21 Cross-Platform Alpha Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to execute this plan task-by-task, `superpowers:test-driven-development` for every product change, and `superpowers:verification-before-completion` before each completion claim. Track progress with the checkbox steps below.

**Goal:** Prove one source architecture on macOS, Windows, and Linux through platform-correct paths, identity, durability, launchers, shortcuts, fonts, local instance transport, bounded diagnostics, and four required GitHub-hosted CI jobs without weakening A17-A20 correctness or storage limits.

**Architecture:** A Qt-free platform policy classifies only macOS, Windows, and Linux and supplies absolute path and native comparison rules. One core durability adapter reports `full`, `file_synced`, or `unsafe` for bounded file publication; settings, setup, session, recovery, and document Save consume that seam without direct-overwrite fallbacks. Qt-only shortcut and font policies are constructed after `QApplication`. Existing service, document, recovery, and session semantics stay shared. A standard-library CI driver executes the owned runtime and validates exact skip/evidence policy across four explicit hosted jobs.

**Tech Stack:** Python 3.12+, PySide6 6.8+, Qt Widgets/QtNetwork, pytest 9+, standard-library `pathlib`/`ntpath`/`os`/`json`/`xml.etree.ElementTree`, POSIX `sh`, Windows `cmd.exe`, GitHub Actions hosted runners, existing UNITI `Document`, `UNITIService`, recovery/session generations, and resource manager.

## Global constraints

- Work directly on local `main`. Each coherent product change ends in a focused commit. Do not create a feature branch or worktree.
- Do not push, tag, publish a release, or create a package artifact without separate user authorization. A21 remote acceptance necessarily pauses at that gate.
- Follow RED → GREEN → refactor: add the focused failing tests, run them and observe the expected failure, implement the minimum shared seam, rerun focused plus inherited gates, then commit.
- Support exactly macOS (`darwin`), Windows (`win*`), and Linux (`linux*`). Unknown platforms fail clearly and never inherit XDG/Linux behavior.
- Keep `src/uniti/core`, `src/uniti/regex`, and `src/uniti/resources` free of Qt and UI imports. OS-specific semantic forks are prohibited.
- Preserve one process-lifetime `UNITIService`, one global Find/Replace panel, multiple windows/panes/views, one authoritative `Document` per native file identity, and explicit Save/Discard/Cancel Quit behavior.
- Preserve editor and Find/Replace histories for saved documents under the A20 first-boundary limits: 50 transactions/states, 32 MiB per document, 4 MiB combined Find/Replace decoded history, 256 MiB saved-history union, seven-day closed-history retention, 512 MiB free-space reserve, and 200 inspected generations.
- Preserve SHA-256 over exact saved bytes as the authority for external edit detection. Metadata identity remains only a fast path.
- No test may manufacture LOWDISK, fill a volume, reserve capacity, or loop large writes. Capacity and durability failures are injected; real probes write only a constant payload in a UNITI-owned temporary directory.
- Document Save remains stage → file flush/fsync → reread/verify → destination identity check → atomic replace. There is no direct-overwrite fallback.
- `full` requires file sync, atomic replacement, and parent-directory sync. `file_synced` requires file sync plus atomic replacement and reports unavailable directory sync. `unsafe` refuses the affected new publication and retains prior durable evidence.
- Session pointer recovery examines at most 200 syntactically valid generation names, validates a complete manifest/pack set, preserves invalid evidence, and repairs the pointer only after a usable generation is selected.
- Persist shortcuts as Qt PortableText under stable command IDs; render NativeText only for presentation. An explicit empty override means “cleared”; absence means “use default.”
- Select an installed concrete fixed-pitch font only after `QApplication`; report `A` and `Ж` coverage. Do not download or bundle fonts.
- Required CI jobs have `permissions: contents: read`, `fail-fast: false`, no `continue-on-error`, no secrets, no deployment/release triggers, and no build/package/upload other than bounded failure diagnostics.
- Failure artifacts retain seven days, contain only sanitized XML/JSON, cap individual files at 2 MiB and the set at 8 MiB, and exclude home/workspace paths, environment dumps, source-document text, recovery/session payloads, and IPC frames.
- Hosted timings are diagnostic only. Do not add timing/RSS thresholds or change the packaged A18-A20 performance policy in A21.

```python
class PlatformFamily(StrEnum):
    MACOS = "macos"

    LINUX = "linux"


def classify_platform(platform_name: str) -> PlatformFamily:
    if platform_name == "darwin":
        return PlatformFamily.MACOS
    if platform_name.startswith("win"):
        return PlatformFamily.WINDOWS
    if platform_name.startswith("linux"):
        return PlatformFamily.LINUX
    raise UnsupportedPlatformError(platform_name)


def absolute_environment_root(
    environ: Mapping[str, str], name: str, fallback: Path

    value = environ.get(name, "")
    candidate = Path(value) if value else Path(fallback)
    return candidate if candidate.is_absolute() else Path(fallback)
```

```python
class NativePath:
    path: Path
    comparison_key: str
    exists: bool


def native_paths_equal(first, second, *, platform_name=sys.platform, cwd=None):
    left = normalize_native_path(first, cwd=cwd, platform_name=platform_name)
    right = normalize_native_path(second, cwd=cwd, platform_name=platform_name)
    if left.exists and right.exists:
        try:

        except OSError:
            pass
    return left.comparison_key == right.comparison_key
```
