# UNITI v0.001a21 Editor Pane Docking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose pane controls, assign open documents to panes, and make document-view undocking reversibly return to its persisted source pane.

**Architecture:** Extend the existing `EditorPaneTree`; do not introduce per-document dock widgets. Persist an optional return anchor on each view, route every detach path through one transactional `UNITIService` transfer, and leave the authoritative `Document` plus registry binding unchanged.

**Tech Stack:** Python 3.12+, PySide6 6.8+ Qt Widgets, immutable dataclasses, canonical bounded JSON, pytest 9+, existing `UNITIService`, `DocumentRegistry`, `WindowManager`, `EditorPaneTree`, `UNITITextView`, and A20 session generations.

**Spec:** [Editor Layout and Visibility design](v0.001a21-editor-layout-visibility-design.md)

Date: 2026-09-05
Status: approved for execution
Plan-set order: 1 of 3

## Global Constraints

- Work directly on local `main`; do not create a branch or worktree.
- Use RED → GREEN → refactor for every product change and finish each task with a focused commit.
- Do not push, tag, release, package, or fill/reserve the real volume.
- Preserve one process-lifetime `UNITIService`, one `DocumentRegistry`, one authoritative `Document` per source identity, and one global Find/Replace surface.
- Docking moves one view and its independent cursor/presentation state; it never moves or clones document text/history authority.
- Splitting immediately creates a second independent view of the active document.
- Assignment selects the first matching tab in the pane or creates another independent view there; it never closes/replaces another view.
- Preserve the 32-window, 128-leaf, 256-view, 128-document, 1 MiB manifest, history, recovery, Quit, and external-file hash limits.
- Existing schema-1 sessions must migrate in memory; future schemas remain rejected and preserved by the store.
- Any failed transfer restores the exact source pane/tab, view state, registry binding, and prior dock anchor.
- Keep `src/uniti/core`, `src/uniti/regex`, and `src/uniti/resources` Qt-free.

```python
SESSION_SCHEMA = 2

class DockReturnRecord:

    def __post_init__(self) -> None:

def _require_placement(value: object) -> str:
    if value not in _FIND_REPLACE_PLACEMENTS:
```

```python
def _split_pane(self, pane_id: str, orientation: Qt.Orientation):
    leaf = self._panes.leaf(pane_id)
    view = self.view_for_id(leaf.selected_view_id) if leaf.selected_view_id else None
    if view is None or self._service is None:
        return None
    editor_snapshot = view.state.export_state()
    new_leaf = self._panes.split_view(view.view_id, orientation)
    clone = self._add_document(view.document, attach_recovery=False, pane_id=new_leaf.pane_id)
    clone.state.restore_state(editor_snapshot)
    clone._state_changed()
    return clone
```

```python
def assign_document_to_pane(self, document_id: str, pane_id: str) -> UNITITextView:
    entry = self._service.documents.get(document_id)
    leaf = self._panes.leaf(pane_id)
    for view_id in leaf.view_ids:
        if self._service.documents.entry_for_view(view_id) is entry:
            leaf.select_view(view_id)
            return self.view_for_id(view_id)
    return self._add_document(entry.document, attach_recovery=False, pane_id=pane_id)
```

- [x] **Step 4: Implement the service transaction and fallback order**

Centralize movement so no UI event calls `take_view_for_transfer` directly:

```python
def undock_view(self, view_id: str):
    source = self.windows.window_for_view(view_id)
    location = source.view_location(view_id)
    target = self.new_window()
    anchor = DockReturnRecord(location.window_id, location.pane_id, location.tab_index)
    return self._transfer_view(
        view_id,
        target.window_id,
        dock_return=anchor,
        close_empty_source=False,
    )


def dock_view(self, view_id: str):
    view = self.windows.window_for_view(view_id).view_for_id(view_id)
    anchor = view.dock_return
    if anchor is None:
        raise ValueError("view is not undocked")
    destination = self._resolve_dock_destination(view_id, anchor)
    return self._transfer_view(
        view_id,
        destination.window_id,
        pane_id=destination.pane_id,
        index=anchor.tab_index,
        dock_return=None,
        close_empty_source=True,
    )
```

In `_transfer_view`, validate destination capacity before `take`, snapshot source location and old anchor, then use `try/except` to reinstall at the exact source and restore the anchor. If `undock_view` created a target before a later step failed, close that empty target during rollback. Close only an empty source window from a successful Dock of an anchored view. Route tab drag, menu Move Tab to New Window, and title button to `undock_view`; when a view already has an anchor, the button calls `dock_view`.
