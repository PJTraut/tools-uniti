# UNITI v0.001a19 — Regex Intelligence Alpha

Date: 2026-09-01
Status: active
Roadmap order: 1

## Goal

Make regex handling a defining UNITI capability.

## Approved focus

- retain third-party Python `regex` as the canonical engine;
- highlight Find regex syntax and Replace replacement syntax;
- recognize inline switches, group numbering/color identity, named groups, and repeated groups;
- provide capture-only Match Reports and useful compile diagnostics;
- make zero-width matches and navigation safe;
- bound result storage, run asynchronously, support cancellation, and invalidate stale results; and
- retain transactional Replace All.

Replacement preview/diff remains optional and enters this milestone only if dogfooding proves it necessary.
