# UNITI v0.001a20 — Recovery & Session Alpha

Date: 2026-09-01
Status: queued
Roadmap order: 5

## Goal

Ensure crashes and restarts do not casually lose work.

## Approved focus

- atomic save and bounded cleanup of stale UNITI-owned temporary state;
- incremental recovery journals, integrity validation, and safe unsaved-edit recovery;
- settings schema migration and corrupted-settings fallback; and
- safe persistence of editor, Find/Replace, and window state.

Recovery never modifies the original file until an explicit commit or save action.
