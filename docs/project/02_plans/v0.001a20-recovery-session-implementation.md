# UNITI v0.001a20 Recovery & Session Alpha Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver one long-lived UNITI service that safely restores admitted document histories, recovery state, windows, panes, views, and the one global Find/Replace panel across restarts while detecting external file changes and bounding all persistent storage.

**Architecture:** A process-lifetime `UNITIService` owns one document registry, multiple window/pane trees, the global Find/Replace panel, session publication, recovery, and Quit coordination. Qt-free immutable records cross the GUI/background boundary; `SessionStore` publishes compressed per-document packs before a bounded manifest/pointer generation, while recovery v3 separately journals semantic transaction events for unsaved work. Single-instance arbitration uses a user-scoped `QLockFile` and `QLocalServer`, and startup restores the active view first before scheduling sealed lazy work through the existing resource manager.

**Tech Stack:** Python 3.12+, PySide6 6.8+, Qt Widgets/QtNetwork, pytest 9+, standard-library dataclasses/enums/JSON/zlib/hashlib, existing `Document`/`EditHistory`, `ResourceManager`/`TaskCoordinator`, atomic file helpers, recovery journals, offscreen Qt and subprocess integration tests.

Status: planned

## Global Constraints

- Exactly one UNITI service owns settings, session, and recovery mutation for one OS-user/application-data identity; a secondary launch forwards activation/file requests and exits.
- The service remains alive after its last editor window closes and terminates only on explicit Quit, logout, shutdown, or process termination.
- One authoritative `Document` is shared by every view of a source; each view independently owns cursor, anchor, preferred column, vertical/horizontal scroll, wrap viewport, and zoom state.
- One service-owned Find/Replace panel serves every window and always targets the most recently focused live editor view.
- Editor history persists the newest 50 logical transactions or 32 MiB decoded per document, whichever boundary is reached first.
- Find history and Replace history each persist at most 50 states, together within one 4 MiB decoded budget using delta encoding.
- Saved session/history data is limited to 256 MiB total and prunes oldest closed-document history first, then oldest inactive-open history, then oldest active-document transactions; current state is never evicted.
- Compatible closed-document history is retained for seven days, subject to the aggregate saved-history budget.
- Unsaved recovery is outside saved-history LRU eviction; one recovery journal compacts at 64 MiB, and free space below 512 MiB suppresses nonessential history writes and attempts recovery compaction.
- A single transaction larger than the persisted limit remains undoable in-process but is marked non-persistable with a visible cross-restart truncation warning.
- Low-disk tests inject capacity readings and controlled write/fsync exceptions only. No test may fill, reserve, truncate, or otherwise materially reduce real filesystem free space.
- SHA-256 over exact saved bytes is the content authority; size, mtime, inode/file ID, and device/volume identity are only a fast path.
- External changes are never overwritten automatically. Changed files offer Open Disk, Skip, or Discard; missing files offer Locate Matching File, Skip, or Discard.
- Session manifests are at most 1 MiB decoded and restore at most 32 windows, 128 pane leaves, 256 views, and 128 distinct documents.
- Per-document packs and recovery records validate schemas, counts, positions, encoded/decoded lengths, checksums, and containment before allocation or replay.
- Session packs are written and synced before their manifest, and the manifest is written and synced before the current-generation pointer is atomically replaced.
- The immediately previous complete session generation remains available until a later generation has published successfully.
- Recovery v1/v2 remains readable; v3 records transactions, Undo, Redo, save points, metadata, checkpoints, and terminal state.
- Hashing, serialization, compression, fsync, recovery replay/compaction, scanning, and cleanup never run on the GUI thread.
- Restored expressions are reanalyzed through the a19 debounce/task path but never automatically execute Find All or Replace.
- Qt stays absent from `src/uniti/core`, `src/uniti/regex`, and `src/uniti/resources`.
- Existing a17 text-integrity, a18 resource/performance, and a19 regex-intelligence contracts remain mandatory.
- Every behavior change follows RED -> GREEN -> refactor and ends in a focused commit on local `main`; no tag or push is part of A20 unless separately authorized.

    TRANSACTION = "transaction"
    UNDO = "undo"
    REDO = "redo"
    SAVE_POINT = "save_point"
    METADATA = "metadata"
    TERMINAL = "terminal"


@dataclass(frozen=True, slots=True)
class HistoryEvent:
    kind: HistoryEventKind
    transaction: EditTransaction | None
    cursor: int
    saved_cursor: int | None
    revision: int
    coalesce: str | None
    metadata: Mapping[str, object]


@dataclass(frozen=True, slots=True)
class HistoryTruncation:
    reason: str
    dropped_transactions: int
    dropped_bytes: int


@dataclass(frozen=True, slots=True)
class HistorySnapshot:
    transactions: tuple[EditTransaction, ...]
    cursor: int
    saved_cursor: int | None
    coalesce: str | None
    decoded_bytes: int
    persistable: bool = True
    truncations: tuple[HistoryTruncation, ...] = ()

    @classmethod
    def empty(cls) -> "HistorySnapshot":
        return cls((), 0, 0, None, 0)


def estimate_transaction_bytes(transaction: EditTransaction) -> int:
    return 32 + sum(
        24
        + len(operation.deleted_text.encode("utf-8"))
        + len(operation.inserted_text.encode("utf-8"))
        for operation in transaction.operations
    )

def add_history_listener(
    self, listener: Callable[[HistoryEvent], None]
) -> Callable[[], None]:
    self._ensure_open()
    self._history_listeners.append(listener)

    def remove() -> None:
        try:
            self._history_listeners.remove(listener)
        except ValueError:
            pass

    return remove


def _notify_history(
    self,
    kind: HistoryEventKind,
    transaction: EditTransaction | None = None,
    coalesce: str | None = None,
    metadata: Mapping[str, object] | None = None,
) -> None:
    event = HistoryEvent(
        kind=kind,
        transaction=transaction,
        cursor=self._history.cursor,
        saved_cursor=self._history.saved_cursor,
        revision=self._revision,
        coalesce=coalesce,
        metadata=dict(metadata or {}),
    )
    for listener in tuple(self._history_listeners):
        listener(event)
```

def verify_saved_file(
    path: Path,
    expected: SavedFileStamp,
    *,
    cancelled: Callable[[], bool] = lambda: False,
    progress: Callable[[int, int], None] | None = None,
) -> FileMatch:
    try:
        actual = FileIdentity.from_path(path)
    except FileNotFoundError:
        return FileMatch.MISSING
    if actual == expected.identity:
        return FileMatch.EXACT_FAST
    return (
        FileMatch.EXACT_HASH
        if sha256_file(path, cancelled=cancelled, progress=progress) == expected.sha256
        else FileMatch.CHANGED
    )
```
