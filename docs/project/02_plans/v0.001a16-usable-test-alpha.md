# UNITI v0.001a16 — Usable Test Alpha

Date: 2026-09-01
Status: active
Roadmap order: 1

## Goal

Make UNITI usable enough for routine daily editing and search work so real use exposes friction and defects. This is an implementation and dogfood milestone, not an architecture expansion.

## Core editor exit scope

- Undo and Redo with a maximum of 50 document transactions.
- Cut, Copy, Paste, and Select All.
- Zoom In, Zoom Out, and Reset Zoom, including primary-modifier mouse-wheel zoom.
- Soft Line Wrap toggle, default off and display-only.
- Go to Line.
- conventional page, document-start/end, and Unicode-aware word navigation with Shift selection extension;
- Reload/Revert from disk with unsaved-change protection.
- concrete fixed-pitch font coverage for Western/Latin and Cyrillic text.

Editor zoom and wrap state are remembered. Status shows editor zoom plus `Wrap` or `No Wrap`.

## Floating Find/Replace exit scope

- Replace the embedded panel with a modeless floating utility window; the document remains editable while it is open.
- Give Find/Replace its own Zoom In, Zoom Out, and Reset Zoom independent of editor zoom.
- Give the Find and Replace fields separate histories capped at 50 undo steps each; focus decides whether Undo/Redo targets the document, Find field, or Replace field.
- Provide a single `[ ] Regex` mode switch.
- Literal mode exposes Case Sensitive and Whole Word.
- Regex mode hides those convenience modifiers and passes raw syntax and inline switches to the authoritative third-party `regex` engine.
- Provide Match Report locations `Hidden`, `Bottom`, and `Right`.
- Regex Match Report displays capture groups `1..N` only, never group `0`; unmatched optional groups retain their numbers, named groups retain the numeric identity, and a delimiter separates matches.
- `Esc` hides the utility without changing the document.

Persist F/R zoom, size/position, and report location independently from editor zoom and wrap state.

## Replace safety

- A single replacement is a document transaction and is undoable.
- Replace All is one atomic document transaction and therefore one Undo operation.
- Saving does not clear document Undo history; loading or reloading a document creates fresh history; a new edit after Undo discards the redo branch.

## Hotkeys

- Add a top-level `Hotkeys` control with the horizontal categories `File | Editing | Navigation | Find/Replace | Editor View | F/R View`.
- Display `Command | Default | Current` rows.
- Allow assign/change, clear, same-scope collision detection, reset selected, reset category, and reset all.
- Persist shortcut overrides between sessions.
- Use `WINDOW`, `EDITOR`, and `FIND_REPLACE` scopes so identical physical keys are valid in disjoint focus scopes.
- Menus and shortcuts share one command registry and handlers. No toolbar is added.

## Durable boundaries

- Qt remains presentation/input; the UNITI `Document` and its transaction history remain authoritative text state.
- `regex==2026.5.9` remains the sole regex-semantics authority.
- Soft wrap remains lazy/virtualized and must not change EOLs or trigger a whole-document layout.
- New persistence uses existing platform-neutral settings and `pathlib.Path` services.
- No hard-coded home paths, drive letters, or path separators enter application logic.
- No extra feature scope is admitted except an obvious basic-editor omission discovered during real testing and required to remove blocking friction.

## Acceptance gate

The milestone freezes only when all five gates pass:

1. the full automated suite is green;
2. deep self-check is green;
3. macOS GUI smoke is green;
4. UNITI has been used for real editing/search work and all blocking/basic usability defects found have been fixed; and
5. no known data-loss or text-integrity bug remains.

## Documentation boundary

Maintain only current architecture, durable design principles/decisions, project grammar, planning state, and handover continuity. Do not create a user manual, feature tour, or end-user feature documentation during a16.
