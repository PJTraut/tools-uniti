# UNITI v0.001a16 Usable Test Alpha Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make UNITI dependable enough for routine daily editing/search dogfooding while preserving document authority and text integrity.

**Architecture:** Keep text and transaction ownership in the Qt-free `Document`; add focused editor-state, command-registry, settings, and Qt presentation units around it. Replace the embedded Find/Replace panel with one modeless utility whose input histories and zoom are independent, while menus and configurable shortcuts dispatch through the same scoped command registry.

**Tech Stack:** Python 3.12+, PySide6 6.8+, `regex==2026.5.9`, pytest 9+, existing UNITI core/app/resource services.

**Spec:** `docs/project/02_plans/v0.001a16-usable-test-alpha.md`

## Global Constraints

- The document editor, Find field, and Replace field each retain at most 50 undo steps.
- Replace All is exactly one document Undo operation.
- Qt never owns authoritative document text.
- `regex==2026.5.9` remains the sole regex-semantics authority.
- Literal Case Sensitive and Whole Word options are absent from regex semantics.
- Soft wrap is display-only, default OFF, remembered, and never creates a whole-document layout.
- Editor and F/R zoom are independent and remembered.
- New paths use `pathlib.Path` and existing platform-aware application roots.
- No toolbar or user manual is added.
- No feature expansion is admitted beyond a blocking/basic editor omission found during dogfooding.
- Every behavior change follows RED → GREEN → refactor and keeps core/regex/resource modules Qt-free.

```python
class EditHistory:
    def __init__(self, max_transactions: int = 50) -> None:
        if max_transactions <= 0:
            raise ValueError("max_transactions must be positive")
        self._max_transactions = max_transactions
        self._transactions: list[EditTransaction] = []
        self._cursor = 0
        self._saved_cursor: int | None = 0

    def _enforce_limit(self) -> None:
        excess = len(self._transactions) - self._max_transactions
        if excess <= 0:
            return
        del self._transactions[:excess]
        self._cursor -= excess
        if self._saved_cursor is not None:
            self._saved_cursor = (
                self._saved_cursor - excess
                if self._saved_cursor >= excess
                else None
            )
```

Call `_enforce_limit()` after appending a non-empty transaction.

def go_to_line(self, line_number: int) -> bool:
    view = self.current_view
    if view is None or line_number < 1:

    try:

    view.state.move_to(target)

    return True

class InputSnapshot:
