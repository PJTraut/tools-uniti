# UNITI v0.001a21 — Cross-Platform Alpha

Date: 2026-09-05
Status: active
Roadmap order: 1

Design: [Cross-Platform Alpha design](v0.001a21-cross-platform-design.md)

## Goal

Prove one canonical architecture on macOS, Windows, and Linux.

## Approved focus

- use `pathlib.Path`, relative project/runtime relationships, and platform-aware config/cache/state roots;
- prohibit hard-coded home paths, drive letters, and separators;
- provide platform-standard shortcuts plus user overrides and concrete installed fonts;
- probe filesystem capabilities;
- pass bootstrap/self-check acceptance on all three OS families; and
- keep packaging outside core text logic.

## Approved delivery boundary

A21 proves the source checkout, bootstrap, tests, deep self-check, and native Qt smoke on GitHub-hosted macOS, Windows, and Linux. It does not produce distributable application packages. The authoritative lean matrix uses Python 3.12 on all three OS families plus the newest stable Python on Linux; physical-machine visual checks are supplemental rather than a completion dependency.
