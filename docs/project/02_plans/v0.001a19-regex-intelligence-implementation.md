# UNITI v0.001a19 Regex Intelligence Alpha Implementation Plan

Date: 2026-09-02
Status: active

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver engine-validated regex authoring, bounded asynchronous capture reports, and deterministic zero-width search and replacement without weakening UNITI's document, text-integrity, or large-file guarantees.

**Architecture:** Qt-free regex modules produce immutable, generation-sealed analysis and report records while the pinned third-party engine remains the sole semantic authority. Two latest-request task slots serialize live compilation and capture resolution, and Qt consumes those immutable results only after checking expression generation, document identity, revision, result-store identity, and match index. Search and replacement retain the a18 snapshot, spill, cancellation, progress, and atomic-transaction paths.

**Tech Stack:** Python 3.12+, PySide6 6.8+, Qt Widgets, pytest 9+, third-party `regex==2026.5.9`, immutable dataclasses, `QSyntaxHighlighter`, `QAbstractListModel`, `QTimer`, existing `ResourceManager`/`TaskCoordinator`, document snapshots, `MatchStore`, and `ReplacementPlan`.

**Spec:** `docs/project/02_plans/v0.001a19-regex-intelligence-design.md`

## Global Constraints

- `regex==2026.5.9` is the only authority for compilation, matching, group numbering, duplicate names, branch reset, repeated captures, and replacement expansion.
- Interactive pattern and replacement expressions are limited to 65,536 Unicode code points; longer text stays editable but cannot compile, search, or replace.
- Live compilation starts only after a 150 ms quiet interval and never runs on the GUI thread.
- Pattern edits advance generation immediately and invalidate search results, replacement analysis, and capture work.
- One Find/Replace window owns exactly one serialized analysis slot and one serialized capture-report slot; a superseded running engine call may finish, but no second call in that slot starts first.
- Each slot retains only its newest pending generation and disposes resources owned by a replaced pending request.
- Cross-thread task notifications are wake-ups; the GUI reads the coordinator's latest monotonically generated snapshot and cannot regress to an older delivery.
- Every published search or report result matches the captured pattern generation, exact field text, document identity, document revision, result-store identity, and requested match index.
- Capture resolution reads no more than 65,536 characters per match, retains at most five previews of at most 80 characters per group, and caps one report payload at 1 MiB.
- A capture report that cannot be complete within a bound returns one explicit unavailable record; it never presents a partial group list as complete.
- Every engine-emitted zero-width match is stored and applied once; navigation advances by stored result index and never fabricates a document selection.
- Replace All remains a monotonic, revision-bound, atomic document transaction and one Undo operation.
- User-authored pattern and replacement text never enters lifecycle logs.
- Qt remains absent from `src/uniti/core`, `src/uniti/regex`, and `src/uniti/resources`.
- Existing a17 exact-format/text-integrity gates and a18 resource, cancellation, performance, and cleanup gates remain mandatory.
- Whitespace visualization, expanded keyboard-driven Unicode inspection, replacement preview/diff, and other excluded features do not enter a19.
- Every behavior change follows RED -> GREEN -> refactor and ends in a focused commit.

```python
@dataclass(frozen=True, slots=True)
class TaskSystemSnapshot:
    generation: int
    background_paused: bool
    tasks: tuple[TaskSnapshot, ...]


def _notify(self) -> None:
    with self._condition:
        self._generation += 1
        self._latest_snapshot = TaskSystemSnapshot(
            self._generation,
            self._background_paused,
            tuple(handle.snapshot() for handle in self._handles.values()),
        )
        listeners = tuple(self._listeners)
    for listener in listeners:
        listener()


def snapshot(self) -> TaskSystemSnapshot:
    with self._condition:
        return self._latest_snapshot
```

```python
def normalize_compile_error(error: regex.error, expression: str) -> RegexDiagnostic:
    raw_position = getattr(error, "pos", 0)
    position = raw_position if isinstance(raw_position, int) else 0
    position = max(0, min(len(expression), position))
    end = position if position == len(expression) else position + 1
    message = str(getattr(error, "msg", None) or "invalid regular expression")
    line = getattr(error, "lineno", None)
    column = getattr(error, "colno", None)
    line = line if isinstance(line, int) else 1
    column = column if isinstance(column, int) else position + 1
    return RegexDiagnostic(
        DiagnosticSeverity.ERROR,
        f"{message} at column {column}",
        position,
        end,
        line,
        column,
    )
```

```python
def _engine_expression(expression, *, literal, case_sensitive, whole_word):
    if not literal:
        return expression, 0
    engine_pattern = regex.escape(expression)
    if whole_word:
        engine_pattern = rf"\b(?:{engine_pattern})\b"
    flags = 0 if case_sensitive else regex.IGNORECASE
    return engine_pattern, flags
```
