# UNITI v0.001a21 Whitespace and Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add bounded whitespace visualization and independent System/Light/Dark plus Standard/High Contrast theme controls without changing text or document coordinates.

**Architecture:** A Qt-free display grammar classifies only bounded visible text. `UNITITextView` overlays markers using its existing `QTextLayout` geometry and a 4,096-operation frame budget, while `ThemeSpec` supplies both the application palette and editor-only color tokens; settings persist mode and contrast globally.

**Tech Stack:** Python 3.12+ `unicodedata`/`enum`, PySide6 6.8+ `QTextLayout`/`QPainter`/`QPalette`, pytest 9+, existing custom `QAbstractScrollArea`, atomic settings schema, and A17 exact-text/save contracts.

**Spec:** [Editor Layout and Visibility design](v0.001a21-editor-layout-visibility-design.md)

Date: 2026-09-05
Status: approved for execution
Plan-set order: 3 of 3

## Global Constraints

- Execute after the [Editor Pane Docking](v0.001a21-editor-pane-docking-implementation.md) and [Find/Replace Docking](v0.001a21-find-replace-docking-implementation.md) plans.
- Work directly on local `main`; use RED → GREEN → refactor and focused commits.
- Whitespace markers are display-only: no text, offsets, selection, clipboard, IME, search, replace, history, recovery, encoding, EOL policy, or save-byte mutation.
- Modes are exactly Off, EOL, Spaces & Tabs, Invisible Unicode, and All.
- Spaces & Tabs means U+0020 SPACE and U+0009 TAB.
- Invisible Unicode means other `str.isspace()` characters plus Unicode category `Cf`.
- EOL markers describe the actual logical terminator (`LF`, `CRLF`, or `CR`); an unterminated final line has none.
- Paint only existing bounded visible slices, perform at most 4,096 marker draw operations per frame, and aggregate overflow visibly as `+N`.
- Theme axes are independent: System/Light/Dark plus Standard/High Contrast.
- High Contrast primary text/base is at least 7:1; meaningful whitespace labels/strokes are at least 4.5:1 against their immediate background.
- Existing settings migrate to whitespace Off and Standard contrast; an invalid new field does not erase valid unrelated fields.
- Keep `src/uniti/core`, `src/uniti/regex`, and `src/uniti/resources` Qt-free.
- Preserve all A17–A21 safety, scale, history, session, Quit, and external-file identity contracts.
- Do not push, tag, release, package, or manufacture LOWDISK.

Use `unicodedata.category` and an explicit known-label table; never import PySide6:

```python
class WhitespaceMode(StrEnum):
    OFF = "off"
    EOL = "eol"
    SPACES_TABS = "spaces_tabs"
    INVISIBLE_UNICODE = "invisible_unicode"
    ALL = "all"


_KNOWN_LABELS = {
    "\u00a0": "NBSP",
    "\u202f": "NNBSP",
    "\u200b": "ZWSP",
    "\u200c": "ZWNJ",
    "\u200d": "ZWJ",
    "\u2060": "WJ",
    "\ufeff": "BOM",
}


def _is_invisible_unicode(character: str) -> bool:
    return (
        character not in {" ", "\t", "\r", "\n"}
        and (character.isspace() or unicodedata.category(character) == "Cf")
    )
```

`iter_character_markers` validates the enum, scans once, yields ASCII markers only for `SPACES_TABS`/`ALL`, and Unicode markers only for `INVISIBLE_UNICODE`/`ALL`. The fallback label is `f"U+{ord(character):04X}"`.

- [x] **Step 4: Implement the exact line terminator query**

Use line-index boundaries rather than materializing line content:

```python
def line_terminator(self, line: int) -> str:
    self._ensure_open()
    content_end = self.line_end(line)
    try:
        next_start = self._document_line_index.line_start(line + 1)
    except ValueError:
        return ""
    if next_start - content_end not in (0, 1, 2):
        raise RuntimeError("line index exposed an invalid terminator width")
    terminator = self._piece_table.read(content_end, next_start)
    if terminator not in ("", "\n", "\r\n", "\r"):
        raise RuntimeError("line index exposed an invalid terminator")
    return terminator
```

```python
@dataclass(slots=True)
class _MarkerBudget:
    remaining: int = MAX_WHITESPACE_MARKERS_PER_FRAME
    overflow: int = 0


def _consume_marker(budget: _MarkerBudget) -> bool:
    if budget.remaining > 1:
        budget.remaining -= 1
        return True
    budget.overflow += 1
    return False
```
