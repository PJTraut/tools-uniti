# UNITI v0.001b3 — Find/Replace Rework & Editor Refinement Beta

Date: 2026-09-15
Status: active
Roadmap order: 1
Feedback: [Beta Feedback Log](../BETA_FEEDBACK.md)

Current source identity: `v0.001b3` / `0.1b3`. All reviewed BF-012–BF-057 source code integrated on `main` is in scope below. The user-directed promotion and separation of source identity from release qualification are recorded in [ADR-0008](../05_decisions/ADR-0008-b3-version-and-qualification.md), continuing [ADR-0007](../05_decisions/ADR-0007-beta-source-version-and-qualification.md)'s B1→B2 pattern.

## Goal

Validate and refine the integrated beta source produced since B2 — dominated by the P1 Find/Replace job/result-model refactor and its dependents, file-type syntax highlighting, and a menu-bar restructuring — close the remaining feedback checks, and retain evidence-based qualification for executable delivery.

## Release qualification boundary

B3 source development is active. Qualified executable delivery still requires the outstanding A22 real-use days, A23 executable health/recovery delivery, A24 stabilization, and B1 fourteen-day independent executable feedback with three testers covering macOS, Windows, and Linux. These gates remain open; source version advancement does not complete their milestones. B2's own outstanding native-host and hosted-CI confirmations (BF-001–BF-010) also remain open and are unaffected by this promotion.

Physical Chinese/Korean IME qualification, affected-host BF-002 confirmation, and same-commit hosted validation remain pending. See [Current Status](../01_current/STATUS.md) for evidence and [Roadmap](ROADMAP.md) for the qualification order.
