# UNITI v0.001a12 Editing Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make ordinary typing and giant-line navigation remain bounded enough for UNITI's 10-100 MB design workload.

**Architecture:** Coalesce sequential edit-store appends/pieces before replacing the list model wholesale. Add bounded line-window navigation APIs and horizontal viewport character windows so rendering/navigation do not materialize entire giant lines. Preserve lazy EOF behavior.

**Tech Stack:** Python 3.12+, pytest, optional PySide6.

**Spec:** `docs/superpowers/specs/2026-08-31-uniti-v0.001a11-a15-remediation-design.md`

## Global Constraints
- No whole-file decode for open/navigation.
- Existing PieceTable/Document public semantics remain stable.
- Giant-line viewport reads remain bounded.
- Version: `v0.001a12` / `0.1a12`.
