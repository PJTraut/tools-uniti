# UNITI v0.001a3 Edited Navigation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add progressive, piece-aware edited-document line navigation without forcing whole-file decoding.

**Architecture:** `DocumentLineIndex` stores logical line starts as `array('Q')` character offsets over the current piece-table text. It indexes through bounded `PieceTable.read()` windows, carries pending CR state across windows, and invalidates from the logical line containing an edit. `Document` delegates public line APIs to this index and reports edit ranges so invalidation is precise.

**Tech Stack:** Python 3.12+, `array('Q')`, existing UNITI `Document`/`PieceTable`, pytest.

**Spec:** `docs/superpowers/specs/2026-08-31-uniti-v0.001-alpha-completion-design.md`

## Global Constraints

- `uniti.core` imports no PySide6.
- Logical document coordinates are Unicode character offsets.
- Opening a file must not decode the whole source.
- CR, LF, CRLF, mixed EOL, multibyte encodings, invalid source bytes, and one enormous line must be supported.
- Version after this milestone is display `v0.001a3`, packaging `0.1a3`.
