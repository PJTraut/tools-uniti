# UNITI v0.001a13 Search Scalability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bound search/replace memory and make search state revision-safe.

**Architecture:** Introduce a paged MatchStore with memory threshold and temp-file spill. Store only match start/end/group-presence eagerly; resolve detailed captures for current/visible matches from the document/pattern as needed. Bind stores to document revision. Large replacement count uses the existing streaming rewrite path automatically.

**Tech Stack:** Python 3.12+, `regex==2026.5.9`, tempfile/struct, pytest.

**Spec:** `docs/superpowers/specs/2026-08-31-uniti-v0.001a11-a15-remediation-design.md`

## Global Constraints
- Regex execution remains authoritative in third-party `regex`.
- Search RAM is bounded by configured MatchStore memory budget.
- Stale results are never navigated/applied after document mutation.
- Version: `v0.001a13` / `0.1a13`.
