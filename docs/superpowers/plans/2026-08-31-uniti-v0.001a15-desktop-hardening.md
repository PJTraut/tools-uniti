# UNITI v0.001a15 Desktop Alpha Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close remaining Unicode desktop-editor usability gaps and produce the Mac runtime-test candidate.

**Architecture:** Editing policy remains Qt-free in EditorState/Document; Qt handles clipboard/IME presentation only. Invalid-byte annotations are carried from source decoding to bounded view spans. Regex UI group identity consults compiled engine semantics. Runtime tests stay optional in environments without PySide6.

**Tech Stack:** Python 3.12+, optional PySide6>=6.8, `regex==2026.5.9`, pytest.

**Spec:** `docs/superpowers/specs/2026-08-31-uniti-v0.001a11-a15-remediation-design.md`

## Global Constraints
- Unicode input must not depend on Qt owning document text.
- Newline insertion policy is distinct from output EOL conversion.
- Clipboard and IME operations mutate through Document/EditorState only.
- Version: `v0.001a15` / `0.1a15`.
