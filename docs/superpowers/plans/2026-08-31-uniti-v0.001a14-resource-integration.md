# UNITI v0.001a14 Resource Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn resource primitives into one integrated application resource manager and remove recovery fsync from the typing path.

**Architecture:** Application constructs one ResourceManager owning CacheManager, memory policy and PriorityWorkerPool. Documents/search/UI receive it explicitly. OffsetMapper decoded spans register as reclaimable cache; active-document priority can be changed on tab switch. RecoveryManager queues journal writes to a dedicated serial worker and flushes on durability boundaries.

**Tech Stack:** Python 3.12+, optional psutil, threading/queue/futures, pytest.

**Spec:** `docs/superpowers/specs/2026-08-31-uniti-v0.001a11-a15-remediation-design.md`

## Global Constraints
- UI does not own workers independently.
- Cache reclamation never drops edit/history state.
- Recovery durability interval is bounded and flushes on save/close.
- Version: `v0.001a14` / `0.1a14`.
